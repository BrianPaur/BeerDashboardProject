CSV Format Requirements

Your CSV file can use either of these formats:

Tilt Pi Export Format (preferred):
  • Time - Date/time (e.g., "1/15/25 1:37:45 PM")
  • Temp - Temperature in Fahrenheit
  • SG - Specific gravity (e.g., 1.050)
  • Beer - Batch name
  • Color - Tilt color (e.g., "Red", "Green")
  • Comment - Optional comment
Time,Timepoint,Temp,SG,Beer,Color,Comment,RSSI,Uptime
            1/15/25 1:37:45 PM,0,68.5,1.050,IPA Batch 1,Red,,,-78,12345
            1/15/25 2:37:45 PM,1,67.2,1.048,IPA Batch 1,Red,,,-80,12445
Alternative Format:
  • name - Batch name
  • temperature - Temperature in Fahrenheit
  • gravity - Specific gravity
  • color - Tilt color
  • timestamp - Date/time
  • comment - Optional comment
name,temperature,gravity,color,timestamp,comment
            IPA Batch 1,68.5,1.050,Red,2025-01-15 14:30:00,Initial reading
